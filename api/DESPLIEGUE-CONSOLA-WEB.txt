DESPLIEGUE EN GOOGLE CLOUD RUN (SIN INSTALAR SDK EN TU PC)
==========================================================

Requisitos previos
------------------
1. Cuenta en https://console.cloud.google.com
2. Proyecto de GCP creado (ej. "freshcheck-prod")
3. Archivos en api/model/:
   - fruit_multioutput_model.keras   (descargado desde Colab)
   - class_config.json               (ya incluido en el repo)

Facturación: Cloud Run y Cloud Build requieren facturación activada en el proyecto.


OPCIÓN A — Cloud Shell (recomendada, todo en el navegador)
----------------------------------------------------------
No instalas nada en Windows. Cloud Shell ya trae gcloud y Docker.

1. Abre https://console.cloud.google.com → icono ">_" arriba a la derecha (Activar Cloud Shell).

2. Sube tu carpeta api/:
   - En Cloud Shell: menú ⋮ → Upload → sube un ZIP con la carpeta api/
   - O clona tu repo: git clone TU_REPO && cd TU_REPO/api

3. Coloca el modelo:
   mv ~/Downloads/fruit_multioutput_model.keras model/

4. Habilita APIs (solo la primera vez):
   gcloud services enable run.googleapis.com cloudbuild.googleapis.com artifactregistry.googleapis.com

5. Crea repositorio de imágenes (solo la primera vez):
   gcloud artifacts repositories create freshcheck \
     --repository-format=docker --location=us-central1

6. Construye y sube la imagen:
   gcloud builds submit --tag us-central1-docker.pkg.dev/TU_PROYECTO/freshcheck/freshcheck-api:latest .

   (Reemplaza TU_PROYECTO por el ID de tu proyecto GCP)

7. Despliega en Cloud Run:
   gcloud run deploy freshcheck-api \
     --image us-central1-docker.pkg.dev/TU_PROYECTO/freshcheck/freshcheck-api:latest \
     --region us-central1 \
     --allow-unauthenticated \
     --memory 2Gi \
     --cpu 2 \
     --timeout 300 \
     --port 8080 \
     --set-env-vars "ALLOWED_ORIGINS=*"

8. Copia la URL que aparece (https://freshcheck-api-xxxxx.run.app).

9. En tu PC, crea .env en la raíz del frontend:
   VITE_API_URL=https://freshcheck-api-xxxxx.run.app


OPCIÓN B — Solo consola web (clics, sin terminal)
-------------------------------------------------
1. Artifact Registry → Crear repositorio "freshcheck" (formato Docker, región us-central1).

2. Cloud Build → Historial → "Ejecutar" o conectar repositorio.
   - Sube un ZIP de la carpeta api/ (con el .keras dentro de model/).
   - Usa cloudbuild.yaml incluido en api/.
   - Sustituye TU_PROYECTO en las variables si hace falta.

3. Cuando termine el build, copia la URL de la imagen en Artifact Registry.

4. Cloud Run → Crear servicio:
   - Imagen: la que acabas de construir
   - Puerto: 8080
   - Memoria: 2 GiB
   - CPU: 2
   - Autenticación: permitir invocaciones sin autenticar (para el frontend)
   - Variables: ALLOWED_ORIGINS=*

5. Tras desplegar, usa la URL del servicio en VITE_API_URL.


PROBAR LA API
-------------
Abre en el navegador: https://TU-URL/health  → debe responder {"status":"ok"}

Para analizar una imagen usa Postman o curl desde Cloud Shell:
curl -X POST "https://TU-URL/api/analyze" -F "image=@ruta/imagen.jpg"
